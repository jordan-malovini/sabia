# Logo do SABIÁ

| Arquivo | Uso |
| --- | --- |
| `sabia-horizontal.png` | Pássaro e nome lado a lado (documentos, apresentações) |
| `sabia-galho.png` | Logo principal: pássaro pousado sobre o nome (README) |
| `sabia-passaro.png` | Só o pássaro (símbolo) |
| `sabia-icone-512.png` | Ícone quadrado (favicon, perfil do repositório) |

Versões derivadas:
- **Página web:** favicon e ícone do topo embutidos em `firmware/data/index.html`.
- **Display 128x64:** pássaro em 1 bit em `firmware/include/logo_boot.h`, para `u8g2.drawXBMP`.

Cores: verde `#1B4D2C` no nome, sabiá em marrom e laranja, gota em azul. As imagens são raster (PNG). Para impressão grande ou adesivo da caixa, vale vetorizar.
